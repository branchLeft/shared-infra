# ansible/checks

This folder holds the checks that prove the lock and the workflow. The narrative of each one lives
beside it, in the markdown file of the same name (`ci_select.md` for `ci_select.py`,
`test_ci_gate_order.md` for `test_ci_gate_order.py`), because the CMT-3 gate requires comment
blocks in the code to stay below 11 lines. A check's narrative is its own file, so this page is
not edited to add or change one, and it holds no list of them: the folder is the list.
